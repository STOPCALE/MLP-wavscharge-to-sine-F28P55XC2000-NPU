> 本文回答一个问题: **随机生成一段波形, 网络输出的参数和真值能差多小?**

**规律: 容量↑ 预算↑ 数据↑ 都在稳步降误差, 但边际递减明显。**

## 4. 误差分布切片 (回答"差多小")

分位数口径: **p50** = 一半样本好于此 (典型水平); **p90** = 最差的 10% 低于此 (尾部水平)。

|---|---|---|---|
| sine | **1.2% / 4.4%** | 0.028 / 0.081 | 0.039 / 0.119 |
| triangle | **1.2% / 5.9%** | 0.032 / 0.102 | 0.038 / 0.097 |
| saw | 2.3% / 8.2% | 0.079 / 0.219 | 0.099 / 0.341 |
| square | 3.5% / **18.1%** | 0.149 / 0.445 | 0.266 / **0.626** |
| 全体 | 1.8% / 8.3% | 0.051 / 0.244 | 0.056 / 0.371 |

### 4.2 按频率区间 (k = 窗内周期数)

| 区间 | k 相对误差 p50 / p90 | 说明 |
|---|---|---|
| k 0.5–1 (欠周期) | **7.7% / 25.8%** | 窗内不足一个整周期 → 信息下限, 见 §5.1 |
| k 1–2 | 2.5% / 8.6% | 正常区 |
| k 2–3 | 1.3% / 4.1% | 正常区 |

| 相位误差 | 0.048 / 0.207 rad |
| 重建 RMSE | 0.072 / 0.466 |

## 5. 三个"信息下限" (为什么部分样本测不准 — 不是模型缺陷)

### 5.1 欠周期窗口 (k < 1)
窗内不足一个完整周期时, 只看到一个"弧段"。k 和 φ 通过乘积 k·t+φ 耦合出现在波形里, 单个弧段**无法唯一分离二者**(数学上近似简并)。所以 k 误差被放大 (p90 25.8%)。
反直觉的是: **这种样本的波形重建反而很好** (recon p50 0.059) —— 因为只要拟合好窗内这一段弧, 波形就对了, 尽管参数分解不唯一。**"波形像"和"参数准"在这里是两回事。**

### 5.2 方波边沿 (square)
方波的"信息"集中在跳变边沿上; 边沿位置被 32 点采样栅格量化 (±1 点 ≈ 3% 周期), 再叠加噪声抖动 → duty/相位/重建全面最差 (recon p90 0.63)。这是**采样栅格 + 噪声的联合下限**, 提高模型能力只能逼近它。

### 5.3 低信噪比 (SNR 下界 20 dB)
噪声本身给观测引入不确定性; 20 dB 下参数的理论可辨识精度有限。网络表现已接近"给定观测的最优拟合"水平 (diagnostics: 含噪/无噪过拟合几乎无差)。

## 6. 最终结论 (对"能差多小"的分层回答)

| 场景 | 结论 |
|---|---|
| 正弦 / 三角波, k≥1, 中位水平样本 | ✅ **差得很小**: 频率 ~1.2%, 相位 ~2°, 波形几乎重合 |
| 锯齿波, 中位水平 | ✅ 基本成立: 频率 ~2.3%, 相位 ~4.5° |
| 方波 / 欠周期, 中位水平 | 🌓 频率 ~3.5~7.7%: "接近"但不算"很小" |
| 任意样本最差 10% (尾部) | ❌ 频率误差可达 18~26%: **"全部样本都差得小"做不到** |
| 分类 + 噪声拒识 | ✅ 已达标 (99.92% / 0 误接受) |

**一句话: 大部分样本 (中位及以上) 参数已差得很小、波形基本重合; 但尾部 10% (方波、欠周期、低 SNR) 存在信息下限, 属于"测不准"样本, 需要靠拒识/降级策略处理, 而不是指望模型继续变大。**

### 6.1 专项收尾摘要 (2026-10-08, 详见 `07_专项篇_拒识与方波与部署.md`)

- **拒识 v2 (重建残差质量分)**: 残差与参数误差强相关 (+0.55, 分类置信度对照仅 +0.07), 拒识曲线单调 ——
  "给回归置信度 / 低置信度拒识"需求以工程可落地方式解决 (C 端一次 cheap 重建, 无需新网络)。
- **方波专项 (三条路全部调研)**: 软损失 / 样本加权 / 测试时精化 —— 主结论: **方波参数误差接近观测信息下限**
  (网络已优于逐样本最优拟合); 软损失方案有负面迁移 (不可用); **push6 仍为最终模型**。
- **NPU 部署验证 (128 宽)**: 全链路通过 —— PWCONV×2 上 NPU (空间 1×1 也可), mod.a **16.9 KB**,
  PTQ 后量化近无损 (k_rel 0.097→0.103); 详见 §7 与 07 文件第十五节。

## 7. 若要继续提升 (路径与预期)

| 路径 | 预期收益 | 成本 |
|---|---|---|
| 继续扩容 (1024 宽 / 30 万样本) | k_rel 再 −10~15% (趋势外推), 尾部仍不达标 | 训练时间 ×3~4, 部署 int8 ~560 KB ⚠️ |
| 方波专项 (边沿感知损失 / duty 加权) | 方波 recon 0.38 → ~0.25 (估) | 小, 但可能牺牲其它类 |
| **重建残差质量分 (推荐)** | 不提高精度, 但把"差得大"的样本**标出来拒识** → 输出样本的可靠度可控 | 小 (前向多算一次重建) |
| 收紧使用域 (声明 k≥1, SNR≥25) | 验收标准 8/9 可达 (在该域内) | 零 |
| 板端实测域差 | 未知 (目前全部模拟数据) | 中 (需采样回路) |

### 部署备注 (F28P55x NPU)
- 512×2 骨干 = 285k 参数 ≈ 279 KB int8, 超出片上可用 RAM 的现实规模 → **部署版建议 hidden=128~192** (用 §3 表对照精度回退幅度, 128 宽时 k_rel≈0.057)
- 部署形态: 1×1 卷积重写 (PWCONV), batch=1, 8bit 激活; softmax/反归一化居 C 端
- 量化误差预计再加 3~5% 相对退化 (TI-NPU QAT 后实测为准, 链路在 torch2tinpu 已就绪)
