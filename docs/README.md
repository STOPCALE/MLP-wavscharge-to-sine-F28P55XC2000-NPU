# Charge_Model 学习指南 (先读这份)

> 本工程: 输入 32 点 ADC 窗口 → ① 分类(正弦/方波/三角/锯齿/噪声) ② 回归参数(A, k, φ, offset, duty)。
> 终极目标: 部署到 F28P55x (C2000) 的 NPU 上运行。
> 分工: 实验运行与记录由 AI 负责; 你的任务 = 读懂 + 复述 + 提问。

## 学什么 (6 个知识点)

1. **多任务头结构** — 共享骨干 + 分类头 + 回归头, 为什么要共享
2. **掩码损失 (masked loss)** — 不同类别/参数的有效性不同 (duty 只对方波, 噪声类无回归标签)
3. **目标归一化** — 多参数回归必须去量纲, 否则梯度尺度失衡
4. **相位表示设计** — 环形量 (角度) 用 (cosφ, sinφ) 对偶表示, 本项目最大发现
5. **梯度预算竞争** — 多任务在有限容量下互相抢梯度 (F2 实验的 k 变差现象)
6. **评估口径** — MAE / 圆周误差 / 重建 RMSE; 为什么重建 RMSE 是最终指标
