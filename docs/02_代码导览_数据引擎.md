# 02 代码导览 (上): 数据引擎 — config.py + wavegen.py

> 每块按【原理 / 易错点 / 怎么验证】讲。对照代码读。

## config.py — 全部旋钮

### 任务定义区 (CLASS_NAMES / PARAM_NAMES / PARAM_RANGES)
- 【原理】类别和参数的**编号顺序**就是模型输出的通道顺序, 是工程与 checkpoint 的契约;
  PARAM_RANGES 同时是随机采样的范围和归一化的锚点。
- 【易错点】改 CLASS_NAMES 的顺序会让已训练的 best.pt 语义错位 (类别 0/1 互换); 改 PARAM_RANGES
  等于换了监督目标的定义, 旧模型失效、旧实验结果不可比。
- 【怎么验证】跑训练前看控制台第 3 行打印的 phase_repr / reg_weights / epochs 是否为你想要的配置。

### 三个 dataclass + 两个实验开关
- WaveConfig (窗口长度/噪声) / ModelConfig (网络规模) / TrainConfig (预算与损失)
- `Config.phase_repr`: `"raw"` 或 `"sincos"` ← 相位表示开关
- `TrainConfig.reg_weights`: 5 个参数的回归权重
- 【原理】所有实验只动这一个文件, 保证"一次一个变量"可执行。
- 【易错点】**run_name 不换 = 覆盖历史记录** (runs/<run_name>/ 同名即覆盖)。
- 【怎么验证】改完 config 先看一眼控制台打印, 再开跑。

## wavegen.py — 参数 ↔ 波形 (数据引擎 + 重建器)

### 1) 波形公式 (render 函数)
- 【原理】四种波形统一用 θ = 2πk·t + φ 定义相位, 全部"与 sin 同相":
  - sine: x = A·sinθ + offset
  - square: 相位落在周期前 duty 比例内取 +1, 否则 −1
  - triangle: x = A·(2/π)·asin(sinθ) + offset
  - saw: x = A·(2·frac(θ/2π) − 1) + offset (从 −1 升到 +1)
- 【易错点】如果四种波形的相位约定不统一, 回归头学到的 φ 就"一词多义", 指标会莫名变差。
- 【怎么验证】取 A=1,k=1,φ=0,offset=0 各渲染一条, 画出来: 正弦从 0 上升、方波先高、三角从 0 上升、锯齿从 −1 上升。

### 2) 训练与重建共用同一个 render
- 【原理】"训练数据生成"和"评估时重建"必须是同一套公式 —— 单一事实来源。
- 【易错点】若评估用另一套公式 (或忘了 offset), recon 指标就是假的, 实验结论全部作废。
- 【怎么验证】无噪声档下: render(cls, 真参数) 与数据集的 x 应完全相等 (差 < 1e-6)。

### 3) 归一化 (normalize_params / denormalize_params)
- 【原理】物理参数 → [0,1] 监督目标。raw: φ 直接线性映射; sincos: (cosφ, sinφ) 由 [−1,1] 映射到 [0,1]。
- 【易错点】**列布局**! raw = 5 列 [A,k,φ,off,duty]; sincos = 6 列 [A,k,cos,sin,off,duty]。
  掩码、loss 权重、评估的列索引都要随模式变 —— 错一列, 所有指标悄悄错。
- 【怎么验证】自检: denormalize(normalize(x)) ≈ x; sincos 模式下 atan2(sin,cos) 应还原 φ。

### 4) 数据生成流程 (sample_dataset 五步)
1. 均匀采样类别 (5 类)
2. 均匀采样参数 (按 PARAM_RANGES)
3. render 渲染周期波形
4. noise 类替换为白噪声; 周期类按每样本随机 SNR 叠加测量噪声
5. 生成掩码: noise 类全 0; duty 列只有方波为 1
- 【原理】固定种子 → 可复现; 测量噪声模拟真实 ADC。
- 【易错点】noise 类的 params_raw 是随机垃圾值 —— 必须靠 mask 挡住, 绝不能进损失。
- 【怎么验证】运行 `python wavegen.py` 自检 (打印各张量形状与数值范围); 或手动统计: noise 行 mask 全 0。
