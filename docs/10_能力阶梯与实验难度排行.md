## 0. 先破除迷信: "随口猜对" = 五个可训练组件相乘

现场三例 (全部来自本项目, 每一例都能拆解散步):

| 现场 | 外人看 | 实际拆解 |
|---|---|---|
| QAT 自蒸馏 loss≈600 爆炸, 立刻定位"教师没 ÷128" | "神了" | ①自蒸馏的常识=教师学生同口径 ②loss 量级差 3 个数量级(600 vs 2e-4)→ 一定是系统性错误而非调参问题 → ③去查两边的数值口径 → 命中 |
| 重建正弦变成近 -1 的缓降线, 反推出 `params_to_phys` 漏偏移 5 | "神了" | ①"慢相位"特征 → 推断 k 极小 → 参数来源可疑 ②手算: 若误用 logits 当参数, rec[0] 应=-0.760 ③实测 -0.760 逐位命中 → 定位调用点 |
| VOFA 上"尖峰波", 判断"数据没坏, 是显示语义" | "神了" | ①取**单帧**画曲线 → 形状正确 ②统计**时间轴**: 每帧换类(35fps 下每秒 8.8 次) → 跳变=轮换×时间轴, 非数据缺陷 |

**公式**: 猜对能力 = **模式库 × 假设-验证循环 × 数据获取力 × 数值反推 × 安全网**
五件全是可训练的 (练法见 §4)。"随口"只是因为练到不需要显式回忆拆解步骤。

## 1. 五级能力阶梯 (总览)

| 等级 | 称号 | 一句话特征 | 会做什么 | 典型卡点 | 达成度量 (以"独立完成的坑"为准) |
|---|---|---|---|---|---|
| **L1** | 跑通者 | 按文档能跑, 出错只会百度 | 跑训练 / 跑部署三连 / 烧录 / 看日志 | 报错即卡死; 数字全对但不知含义 | 独立跑通 3 条链路 |
| **L2** | 复述者 | 每个数字能讲清原理; 改参数能预测方向 | 解释指标 / 扫参实验 / 回答复述 D 题 | 遇到**新**错误无从下手 | 能解释 10+ 个实验的机制 |
| **L3** | 定位者 | 从**直接证据**定位: 报错文字 / 对拍差异 / map / 符号表 | 对拍、排除法、nm/map 工具链 | 手上只有"模糊现象"时失效 | 独立解掉 3~5 个"报错级"问题 |
| **L4** | 侦探 | 从**大致数据 / 模糊现象**反推根因; 识破"假象 vs 真 bug" | 数值反推 / 单帧vs时间轴 / 判据设计 | 组合拳还不熟, 闭环偶尔断 | 独立完成 1~2 次"数据反推级"诊断 |
| **L5** | 闭环者 | 自主全流程: 取数→假设→修复→验证→交付, 无需指导 | 写取数脚本 / 自动烧录复测 / 出报告 | —(开始教别人) | 完整闭环 ≥3 次 |

**累计投入估算** (以本项目为样本, 个体差异大, 仅供参考):

| 等级 | 本项目内对应阶段 | 项目内实耗 | 独立掌握累计估算 |
|---|---|---|---|
| L1 | 跑通训练 + saw2sin 部署链 | ~半天 | ~10-20 h |
| L2 | M1→B线→push 扫描 + 复述题库 D 题 | ~1.5 天 | 再 +40-60 h |
| L3 | charge_mtl 结构重写 + QAT + CCS 集成与排查 | ~2 天 | 再 +60-100 h |
| L4 | 拒识v2 / logits÷128 / 指针 bug / 滑窗 | 贯穿各天 | 再 +150 h 以上 |
| L5 | 本轮"读串口→修复→烧录→复测→报告"全闭环 | ~2 h 连续作业 | L4 后多轮完整战役 |

> 更稳的度量不是小时数, 而是 **坑位数**: 本项目累计沉淀 25+ 张"现象→根因"卡 (§4.1), L4 的直觉= 卡库密度。

## 3. 三个高光案例的"思维过程"复盘 (L4 长什么样)

### 案例 1: 指针偏移 bug (本轮, 全程零调试图)

```
看到:  CH46-77 曲线 mean|Δ|=0.003, range[-1.04,-0.97]  → 一条"缓慢下降的近-1线"
第1步: 特征编码 —— "缓慢" = 相位推进慢 = k 极小(0.28级) ≠ 网络正常输出(1.4级)
       → 结论: 计算时拿到的"参数"不是网络刚算的那组
第2步: 对照检验 —— 用同帧参数通道重算理想曲线 → maxdiff=1.9, 完全不符 → 证实猜想
第3步: 假设定位 —— 会拿错什么? 布局是 [logits×5|参数×6] → 试试"忘了偏移5"
       手算: A=0.213, k=0.283, off=-0.572 → 预测 rec[0] = -0.760
第4步: 实测 rec[0] = -0.760 → 逐位命中 → 翻代码 → params_to_phys(g_out) → 确诊
```
**可练点**: 第 1 步的"特征→数量级"翻译 (slow→k小→来源可疑) 是模式库; 第 3 步的"手算预测"是核心习惯。

### 案例 2: "尖峰"是假象还是 bug? (判定树)

```
现象: CH0-31 与 CH46-77 在 VOFA 上都"难看"
分支1: 取"单帧"画曲线 —— CH0-31 成形(正弦/方波/三角/锯齿全对) → 显示语义问题
分支2: CH46-77 单帧也不成形 → 真 bug → 走案例 1 流程
修复语义问题: 统计时间轴(每帧换类 8.8次/秒) → 设计"滑窗"把快照变成连续流
```
**可练点**: "单帧 vs 时间轴"两问是肌肉记忆级的起手式; 假象与真 bug 可以**并存**, 要分开修。

### 案例 3: logits÷128 (前日)

```
现象: int8 量化后参数精度崩坏 (k_rel 0.10→0.68), 而分类完全没事
推理: "分类没事+参数崩" → 输出共享量化 scale → logits(±260) 把 scale 占满
      → 参数([0,1]) 分辨率被挤爆
修复: 把 cls_head 权重/偏置 ÷128 (argmax 不变, 数值缩回温和区) → C 端 softmax 时 ×128 恢复
```
**可练点**: 从"哪个部分坏了/哪个部分没坏"的**对比性症状**出发, 比盯着坏的部分硬看有效得多。

## 7. 自测: 你在第几级? (10 题)

1. 能不看文档把"训练循环四步"说全, 并指出在 train.py 哪一行 → (L2 起步)
2. 能解释"为什么 sincos 比 raw φ 学得好"且说出损失有界性 → (L2)
3. 给你一条新报错, 你会先找"这个符号在哪定义/引用"吗 → (L3)
4. 知道 `nm`/`map`/`readelf` 之类工具是干什么的, 用过至少一次 → (L3)
5. 看到"某个数差 3 个数量级"会先怀疑系统性错误而不是调参 → (L4)
6. 会为一个 bug 先写"如果我的假设对, 手算结果应为 X" → (L4)
7. 看到难看波形, 会先"取单帧画曲线"再下结论 → (L4)
8. 写过一个"直连硬件取数"的脚本 (串口/文件/日志), 并用它做过决策 → (L4→L5)
9. 动手改任何东西前会备份/设回滚点 → (L5 素养)
10. 能在无人指导下独立完成一次: 观察→假设→实验→修复→复测→写报告 → (**L5**)

> 3 个以上 L4 题 + 第 10 题 = 你已经达到"随口猜对"的门槛;
> 剩下的只是坑卡数量的积累——这恰好是最不需要天赋的部分。
